## 0.1.0

* Initial stable release of `flutter_ai_copilot`.
* Real-time streaming response engine with low-latency typewriter rendering.
* Autonomous multi-turn LLM tool calling execution loop.
* Dynamic Generative UI widgets registration for rich tool completion cards.
* Interactive Markdown support with syntax-highlighted code blocks and one-tap copy button.
* Drop-in UI components: `AiChatView`, `AiCopilotFab`, and `AiCopilot.showSheet(context)`.
* Multi-LLM provider support: Google Gemini (2.0/1.5), OpenAI (GPT-4o), Local Ollama, and Mock AI.
* Multimodal vision attachment support (images, screenshots, documents).
* Light and Dark cyber theme presets.
